2. Audit Categories

2.1 Technical SEO

Score: 38/100

What Works

  • Fully prerendered HTML (344 KB with content, no SPA dependency)
  • Proper 404 status for unknown paths
  • robots.txt references the sitemap; AI-training crawler policy already right-shaped
  • Valid single-URL sitemap
  • Viewport meta, lang=en, favicon/apple-icon/manifest present

Findings

No canonical + 4 duplicate URL variants (http/https x apex/www) Critical

All four variants return 200 with no redirect and no <link rel=canonical>; www's sitemap/robots self-report www URLs (host-derived in lib/server-url.ts). lib/seo/metadata.tsx builds metadataBase as new URL('https://https://ahmadsaad.dev/').

Recommendation: Cloudflare Always Use HTTPS + www->apex 301 rule (or middleware.ts); hardcode the base in lib/server-url.ts; metadataBase: new URL(productionUrl); alternates.canonical '/'.

robots.txt disallows /_next/ for every crawler High

Cloudflare-managed and app-generated User-agent: * groups merge; hashed CSS/JS/font chunks under /_next/static/ are blocked for Googlebot.

Recommendation: Remove '/_next/' (and '/public/') from disallow in app/robots.ts.

No security headers High

HSTS, CSP, X-Content-Type-Options, X-Frame-Options, Referrer-Policy and Permissions-Policy are all absent on every response.

Recommendation: Add headers() in next.config.mjs or public/_headers; enable HSTS in Cloudflare.

Hashed static assets not cached immutably Medium

/_next/static/*.css served with Cache-Control: public, max-age=0, must-revalidate.

Recommendation: Cache-Control: public, max-age=31536000, immutable for /_next/static/:path*.

Dead analytics requests on every page load Medium

/stats/script.js (Umami, 404, NEXT_PUBLIC_UMAMI_WEBSITE_ID unset) plus /_vercel/insights/script.js and /_vercel/speed-insights/script.js on a Cloudflare deployment.

Recommendation: Remove the Vercel scripts; render the Umami <Script> only when the env var is set.

Sitemap lastmod changes on every request Medium

app/sitemap.ts uses dayjs() at request time; two fetches 3 s apart returned different lastmod values.

Recommendation: Use a manually bumped content date (code in findings/sitemap.md).

og:image declared 1200x630 but the asset is 1600x836 Medium

createMetadata hardcodes 1200x630; createOgImage generates w_1600,h_836.

Recommendation: Pass the real dimensions from createOgImage.

HTML served with x-nextjs-cache: MISS on every fetch Info

Observed on all fetches; lab TTFB 1.1-1.9 s.

Recommendation: Check the OpenNext ISR/cache configuration so the prerendered page is served from cache.

2.5 Performance (CWV)

Score: 51/100

What Works

  • Desktop LCP 1.4-2.5 s (good/borderline)
  • Mobile CLS 0 (Playwright) / 0.069 (Lighthouse)
  • Cloudflare edge + HTTP/3
  • LCP element is server-rendered text, so no image dependency

Findings

One JS chunk blocks the main thread before the LCP text paints Critical

224-b51a9b702c283363.js (174 KB) runs a single long task (~7 s at 4x throttle, 2.1 s desktop); mobile LCP 6-13 s, TBT up to 6.6 s. Compounded by the RevealOnLoad opacity animation on the intro.

Recommendation: Code-split heavy client components with next/dynamic({ssr:false}); render the hero visible by default; tighten browserslist to drop ~12 KB of polyfills.

TTFB 1.1-1.9 s on every run with x-nextjs-cache: MISS Critical

The prerendered page appears to be rendered on the Worker per request; 0 ms edge RTT, so the delay is origin work.

Recommendation: Fix the OpenNext/Cloudflare cache so the HTML is served from cache; target TTFB < 0.8 s.

5 carousel JPEGs (400 KB, ~41% of page weight) eagerly preloaded and 30x oversized Critical

5x <link rel=preload as=image>; ~347 KB wasted per Lighthouse; never the LCP element.

Recommendation: next/image with sizes/srcset and width/height; priority only on the active slide; lazy-load slides 2-5; drop the preloads.

CLS 0.07-0.11 across runs High

Desktop culprit is the unsized carousel (0.097 of 0.106); mobile culprit is an accordion hydration race plus font swap.

Recommendation: Reserve space for the carousel and the collapsible panels; open the default-expanded panel server-side.

No preconnect hints, 23 KB render-blocking CSS, Cloudflare Insights beacon ~0.66 s avoidable LCP delay High

Lighthouse critical-path audit.

Recommendation: Add preconnect for remaining third-party origins; defer the beacon; inline critical CSS.

3 dead analytics requests per load Medium

/stats/script.js (404), /_vercel/insights/script.js and /_vercel/speed-insights/script.js (wrong platform).

Recommendation: Remove the Vercel scripts; gate Umami on its env var.

Hashed assets not cached immutably; 4 font preloads incl. one .otf Medium

Cache-Control max-age=0 on /_next/static; ~20 async JS chunks (309 KB) incl. motion + shooting-stars canvas.

Recommendation: Immutable cache rule for /_next/static/*; keep <= 2 font preloads; lazy-load decoration.
