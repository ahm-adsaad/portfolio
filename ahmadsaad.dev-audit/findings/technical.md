# Technical SEO Audit — ahmadsaad.dev

Audited: 2026-08-24 · Single-page personal portfolio (Next.js 15 App Router, prerendered/SSR, OpenNext on Cloudflare Workers).
Source checked: `C:/Users/ahmad/Desktop/GitHubRepos/portfolio/apps/website` (app/robots.ts, app/sitemap.ts, app/layout.tsx, app/page.tsx, lib/seo/metadata.ts, lib/seo/json-ld.tsx, lib/server-url.ts, middleware.ts, next.config.mjs, wrangler.jsonc, features/home/components/project-coverflow.tsx, components/ui/coverflow-carousel.tsx).

## Score: 38 / 100

Crawlability and base indexability fundamentals are solid (prerendered HTML, valid sitemap, no accidental noindex), which keeps this from scoring lower. The score is dragged down by a cluster of concrete, verified config bugs that are unusual to see together: zero security headers on any response, no canonical tag combined with four live duplicate host/scheme variants that are actively reinforced by a host-derived sitemap/robots implementation, a robots.txt that blocks Googlebot from all CSS/JS/font assets, and an empty/invalid JSON-LD block. All are cheap, well-scoped fixes.

## What works

- Homepage is server-rendered/prerendered (`x-nextjs-prerender: 1`) — full text content, headings, and links are present in the initial HTML with no JS execution required for indexing.
- `sitemap.xml` is discoverable via `robots.txt`, returns HTTP 200, valid `urlset`, correct `Content-Type: application/xml` (confirmed with `sitemap_discovery.py`).
- No accidental `noindex`: no `<meta name="robots">` on the page, no `X-Robots-Tag` header, robots.txt does not block `/`.
- `<meta name="viewport" content="width=device-width, initial-scale=1">` present with no `maximum-scale`/`user-scalable=no` lock — mobile-friendly baseline is correct.
- 404s return a real 404 status with a proper not-found page (not a soft-404).
- 4 web fonts are preloaded, reducing font-swap-related layout shift for text content.
- Favicons, apple-touch-icon, SVG icon, and `manifest.json` (valid JSON, correct icon sizes) are all present and resolve.
- Site content itself is not thin/duplicated internally — it's a genuinely single, intentional page.
